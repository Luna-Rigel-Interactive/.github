# Luna Rigel Interactive

**Interactive stories, games, and digital worlds.**

Luna Rigel Interactive is an independent creative label focused on narrative games, visual novels, and interactive experiences for PC and mobile.

We build projects where **story, atmosphere, choice, and technology** work together — from intimate character-driven narratives to experimental interactive systems.

## Current project

### *Lo que queda de nosotros*
A narrative visual novel developed with **Ren'Py**.

The project is currently in active development. Its first playable baseline has already been established, with branching choices, save/load systems, provisional audiovisual assets, and a complete prologue structure.

## What we make

- Narrative games and visual novels
- Interactive fiction
- Experimental game systems
- PC and mobile experiences
- Tools and pipelines for interactive storytelling

## Our approach

We value clear authorship, maintainable code, deliberate visual direction, and iterative development. Prototypes are allowed to look like prototypes; important ideas are preserved, tested, refined, and only then promoted into production assets.
